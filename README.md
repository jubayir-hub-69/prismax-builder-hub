## 🚀 Key Features

- **Discord Username Authentication**: Seamless mock login state using native browser prompts.
- **Fully Functional "Submit Build" Form**: A robust project submission system with global state management and persistent data across sessions via `localStorage`.
- **Real-time Project Search & Filters**: Instantly filter projects by robotics categories or search by builder names and keywords.
- **Premium "Bento Box" Grid UI**: Award-winning design aesthetics featuring heavy glassmorphism, dynamic glowing orbs, and deep interactive shadows.
- **Groundbreaker Showcase**: Automatically highlights top community members based on their project contributions.
- **Cybernetics & Robotics Overlay**: A fixed, system-wide technical background grid and subtle radial glow to ground the UI in the PrismaX futuristic brand.
- **Fluid Micro-interactions**: Magnetic buttons, sleek scroll-tied navigation, and perfectly tuned hover transitions (`60fps`).

## 🛠️ Tech Stack

Built for maximum performance, SEO, and visual fidelity using modern web technologies:

- **Framework**: [Next.js](https://nextjs.org/) (App Router & Server Components)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (using custom `@theme` variables)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom inline SVGs for brand identities (GitHub, Twitter, YouTube)
- **State Management**: React Context API & `localStorage`
- **Build Tool**: Turbopack for ultra-fast HMR

## ⚙️ Getting Started

Ready to run the Hub locally? Follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/jubayir-hub-69/prismax-builder-hub.git
cd prismax-builder-hub
```

### 2. Install dependencies
```bash
npm install
```
*Note: Make sure you have Node.js 18+ installed on your system.*

### 3. Start the development server
```bash
npm run dev
```

### 4. Open the application
Navigate to [http://localhost:3000](http://localhost:3000) in your browser. Try logging in and submitting your first Web3 Robotics project!
